# 🎙️ SayIt 剪贴板保底 & 智能自愈管家 (SayIt Clipboard Guardian) v2.0

> **专为 SayIt 语音输入打造的全自动防丢失与智能自愈守护插件**。
> 1. **双重剪贴板锁定**：只要识别成功，0ms 毫秒级锁定剪贴板，彻底防止被 SayIt 原生 400ms 还原动作冲掉。
> 2. **网络断连/超时智能自愈**：当长语音因网络卡顿或心跳超时导致 SayIt 界面报“无有效声音/识别失败”时，管家后台**自动探测、毫秒级直连云端重新转录**，自动将完整文本送入剪贴板并回写修复数据库！
> 3. **误触智能过滤**：自动识别并忽略 ≤ 3.0 秒的空音频误触，不打扰正常工作。

---

## 📌 为什么需要它？（痛点与原理）

1. **痛点 1：输入法与焦点冲突导致文字丢失**
   - **现象**：SayIt 在识别成功后，会把文字写入剪贴板 ➔ 模拟按键粘贴 ➔ **在 400ms 后自动将剪贴板还原为旧内容**。在管理员窗口、无焦点桌面、全屏游戏或不兼容输入框中，模拟粘贴失败，剪贴板又被还原，导致整段语音彻底丢失。
   - **解决**：管家在 0ms 即时写入，并在 480ms 处（精准穿透 SayIt 的 400ms 还原动作）**二次加固覆盖**，确保剪贴板中始终是您刚说的内容。

2. **痛点 2：网络波动/心跳超时导致长语音变“无有效声音”**
   - **现象**：长语音（如 3~5 分钟）在上传云端识别过程中，若遇网络抖动触发 WebSocket 心跳超时（如 code 4000），SayIt 客户端会触发 45s 超时中断，界面显示“无有效声音”，文字留空。用户不得不手动打开历史记录、等待刷新、翻找、点击“重新识别”、等待、再点击“复制全部”，极其繁琐且打断心流。
   - **解决**：管家后台持续监听 SQLite 数据库流。一旦捕获到转录失败且音频有效时长 > 3.0s，**立即自动在后台启动重试引擎**，读取本地 `.wav` 原声直连云端通道重转录，拿到文本的第一时间**自动锁定送入 Windows 剪贴板并修复历史记录**！主人无需点开任何界面，直接按 `Ctrl + V` 即可粘贴！

3. **痛点 3：极短误触噪音干扰**
   - **解决**：对时长 ≤ 3.0 秒且无文本的录音（如误触开启又立即关闭），自动静默忽略，不占用任何系统资源。

## 🚀 极简使用与功能说明

| 控制脚本 / 文件 | 功能说明 |
| :--- | :--- |
| **`🚀 启动SayIt剪贴板保底管家.bat`** | 在后台静默拉起保底管家（无黑框、内存占用 < 20MB，CPU 0.00%） |
| **`🛑 停止SayIt剪贴板保底管家.bat`** | 结束后台守护进程 |
| **`📊 查看运行状态与最新转录.bat`** | 查看当前运行状态与最新捕获的语音识别文本与自愈日志 |
| **`⚙️ 设置开机自启动.bat`** | 一键将管家加入 Windows 启动项，每次开机全自动在后台守护 |
| **`❌ 取消开机自启动.bat`** | 一键从 Windows 启动项中移除 |
| **`setup.ps1`** | PowerShell 标准一键部署与自启脚本 |
| **`uninstall.ps1`** | PowerShell 标准一键卸载脚本 |
