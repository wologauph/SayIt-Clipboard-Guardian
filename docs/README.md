# 🎙️ SayIt 剪贴板常驻保底管家 (SayIt Clipboard Guardian)

> **专为 SayIt 语音输入打造的防丢失外挂守护插件**。无论目标窗口是否获得焦点、是否为管理员权限窗口、或是否支持输入法粘贴，只要 SayIt 完成语音转文字，**100% 自动将最终文本置入并锁定在 Windows 剪贴板中**，随手按 `Ctrl + V` 即可瞬间粘贴，彻底告别语音丢失！

---

## 📌 为什么需要它？（痛点与原理）

1. **SayIt 原生逻辑**：
   SayIt 在识别出文字后，会临时把文字写入剪贴板 ➔ 模拟键盘按键粘贴 ➔ **在 400ms 后自动将剪贴板还原为旧内容**。
2. **引发的痛点**：
   当用户在无焦点桌面、管理员权限窗口、游戏全屏或不兼容文本框中说话时，SayIt 的模拟粘贴会失败；同时剪贴板又被它还原成了旧内容，导致**屏幕上没出字，剪贴板里也没有，整段语音彻底白说**。
3. **保底管家的解决方案**：
   - 毫秒级监听 SayIt 本地数据库 SQLite WAL 流水；
   - 识别完成瞬间立即写入剪贴板；
   - 并在 480ms 处（精准穿透 SayIt 自身的 400ms 还原动作）**二次加固覆盖**；
   - 确保剪贴板中的内容始终是您刚刚说的这句话！

## 🚀 极简使用与功能说明

| 控制脚本 / 文件 | 功能说明 |
| :--- | :--- |
| **`🚀 启动SayIt剪贴板保底管家.bat`** | 在后台静默拉起保底管家（无黑框、内存占用 < 15MB，CPU 0.00%） |
| **`🛑 停止SayIt剪贴板保底管家.bat`** | 结束后台守护进程 |
| **`📊 查看运行状态与最新转录.bat`** | 查看当前运行状态与最新捕获的 5 条语音识别文本 |
| **`⚙️ 设置开机自启动.bat`** | 一键将管家加入 Windows 启动项，每次开机全自动在后台守护 |
| **`❌ 取消开机自启动.bat`** | 一键从 Windows 启动项中移除 |
| **`setup.ps1`** | PowerShell 标准一键部署与自启脚本 |
| **`uninstall.ps1`** | PowerShell 标准一键卸载脚本 |
